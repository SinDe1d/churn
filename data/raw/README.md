# Dataset source

`telco_churn.csv` est le fichier public **WA_Fn-UseC_-Telco-Customer-Churn.csv**
fourni dans l'archive du projet. Il contient 7 043 clients et les variables de
services, contrat, facturation et churn utilisées par le pipeline.

Le pipeline ne télécharge pas de données à l'exécution: la source est versionnée
localement pour rendre le projet reproductible et directement clonable sur GitHub.
